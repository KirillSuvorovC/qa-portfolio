Страница для проверки: [Магазин](https://guru.qahacking.ru/index.php/magazin)

**Предусловия**:
- Карточка товара:
  - Выбрать любой продукт из списка

**Проверить**
- Сортировка товаров
  - [ ] По цене (возрастание)
  - [ ] По цене (убывание)
  - [ ] По названию (А-Я)
  - [ ] По названию (Я-А)
- Карточка товара
  - [ ] Добавление продукта в корзину (количество = 1)
    **Ожидаемый результат**: Перенаправляет на страницу корзины
  - [ ] Добавление продукта в корзину (количество = 0)
    **Ожидаемый результат**: Ошибка валидации
