# Веб-тестирование
Я протестировал [сайт](https://guru.qahacking.ru/index.php/magazin) магазина,
предназначенный для поиска товаров и оформления заказов.

**Цель**: проверить, что пользователь найдет товар, добавит в корзину и оформит
заказ.

**Что тестировать**:
- Поиск и фильтрация товаров
- Карточка товара
- Корзина: добавление, изменение и удаление товара 
- Оформление заказа

**Что не тестировать**:
- Производительность: не входит в цель
- Безопасность: требует отдельного подхода
- Мобильная версия: проверка только на ПК

**Риски**:\
Проверить критические сценарии:
- Оформление заказа, поскольку он влияет на выручку
- Поиск товаров - без него не найти продукт для оформления заказа
