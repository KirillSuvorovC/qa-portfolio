### Проверка пагинации товаров, используя фильтр поиска

**Окружение**: Chrome 157.x, Windows 10 64 bit, URL: https://guru.qahacking.ru/index.php/magazin

**Что проверялось**:\
Поведение изменения количества отображаемых товаров:
- [x] Через предоставляемый список в фильтре поиска, применяя Эквивалентное разделение:
  каждый пункт из списка - отдельный класс
- [ ] Через свои собственные значения из списка в фильтре поиска, используя DevTools (вкладка Elements),
  применяя граничные значения: -1, 0, 1, 7, 8, 9.
  Последние 3 цифры, потому что в магазине всего 8 товаров.

**Баги**:
- ([BUG-005](/bug-reports/BUG-005.md)): Расхождение количества отображаемых товаров с выбранным количеством в фильтре поиска
